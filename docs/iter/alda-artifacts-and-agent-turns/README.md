# Alda 音频产物与 Agent 回合闭环

## 原始问题

一次创作交互中，Agent 把“Alda 语法通过”解释成“可以听到声音”，没有真实渲染或播放；用户要求数分钟
作品后，模型只重新排列了短素材并错误声称约三分钟；连续修正又重复踩中 Alda 版本、变量连音和乐器别名
规则，甚至把未通过候选描述成已经发生的修改。

根因不是单个提示词错误，而是三层事实缺失：宿主没有 WAV 产物与静音检测，Agent 没有可调用的真实检查/
渲染/播放工具，提示也没有明确每轮职责及“校验、渲染、播放、保存、接受”的边界。

## 最终实现

- 新增 Alda → MIDI → FluidSynth → WAV 链路；统一导出 `alda`、`midi`、`wav` 或 `all`，报告实际 WAV
  时长、采样率、声道、帧数、peak、RMS 和静音判断。
- Linux 安装脚本和 doctor 纳入 FluidSynth、GM SoundFont 与真实非静音探针，支持
  `ALDA_AGENT_SOUNDFONT`。
- Alda 2.3.3 冷启动导出会先拉起后台 player/JVM；默认命令超时调整为 120 秒，超时和取消仍回收完整
  子进程组。
- 从 Alda 官方 `release-2.4.3`、提交 `33e17e5674fd98da89462f21b2e0e5f2d9f16944` 保存完整
  文档快照、来源和 EPL-2.0 许可证；运行时兼容目标 Alda 2.3.3 继续单独标注。
- 编译进系统提示的精简参考明确独立声部时间轴、别名续写、Alda 2.3.3 不支持拍号等高频规则，示例由
  本机 Alda 2.3.3 自动解析验证。
- Agent 增加 `lookup_alda_docs`、`inspect_score`、`render_score`、`play_score` 和最终
  `submit_result`。工具轮不占修正次数，最多八轮；同源码同错误会停止无进展重试。
- 工具状态机测试覆盖“查询手册 → 检查 → 首次渲染 → 播放 → 最终回答”，并验证首次渲染会自行创建
  `exports/`，不会依赖其他命令预先建目录。
- 请求侧显式关闭并行工具调用；SSE 按 index 独立聚合。供应商仍返回多个调用时，宿主拒绝且不执行全部
  调用，将逐个错误写回后自动继续，不占用乐谱修正轮数；工具往返也不会重复显示同一“第 1/3 轮”。
- 模型只返回普通文本或空响应、没有调用任何宿主工具时，宿主将协议错误写回并自动继续，且不占用乐谱
  修正轮数；这类未提交文本不会被误显示成最终结果。
- 精确或区间自然语言总时长在模型调用前持久化；“数分钟”等模糊描述留给 Agent 追问。“第 3 分钟加入
  小号”“开头 30 秒”等时间轴位置不会被误存为总时长。区间按上下限硬边界校验。结果明确报告工作稿是否真正改变，并区分语法通过、已渲染、
  已播放和已接受版本；播放旧工作稿后提交新稿时会标为“修改前工作乐谱”。
- 创作计划由工具显式提交核心材料、曲式、配器和发展方式，终端展示完整内容，不引用隐藏模型文本；带提问
  意图的 `answer` 由宿主归为 `clarification`。用户明确要求“编写曲目/开始谱曲/编曲/作曲/写一首/直接完成”
  时，提示词要求直接生成完整候选，宿主也拒绝回答、计划或短草稿并在本轮自动要求模型改交 `candidate`。
  用户在可选偏好问题后回答“没有/随意/你决定”等时，宿主继承未完成创作意图、禁止再次澄清并采用合理
  默认值；提示明确禁止无关品牌推广确认，以及在校验前声称精确时长或检查通过。
- 完整候选要求持久化到对话状态，跨任意澄清回答、请求失败和重启保持；回答一次问题后不允许再次陷入澄清
  或无关拒绝。具体品牌名称本身不构成创作阻塞。截断或无效的 `submit_result` JSON 会作为工具协议错误自动
  写回并重试，不再把项目留在“上次请求未完成”。
- `/project config model` 和 `url` 缺参时由终端立即读取配置值；模型配置前置检查失败时不把裸配置值、创作
  请求或时长写入对话与项目。

## 验证证据

- `cargo test`：全部单元、集成和提示示例测试通过。
- `cargo clippy --all-targets --all-features -- -D warnings`：通过。
- `cargo +1.85.0 check --locked`：通过。
- `cargo run -- doctor --probe alda`：Java、Alda、FluidSynth、GM SoundFont、Rust 五项通过。
- 真实一键导出：同时生成 `.alda`、`.mid`、`.wav`；测试 WAV 为 4.45 秒、44.1 kHz、双声道、
  peak 0.0140、RMS 0.0021，非静音。

## 结果边界

这些改造修复了“无事实却声称有声音”“错误估算时长”“重复提交同一失败候选”“别名规则靠猜”和“本轮
到底有没有改变工作稿”等机制问题。它不能自动证明作品听感优良；编曲质量、数分钟长篇结构和真实模型在
长对话中的遵循度仍需用代表性音乐任务人工验收。
