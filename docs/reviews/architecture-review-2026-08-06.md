# 首期架构评审

> 日期：2026-08-06
>
> 范围：切片 0–5 当前工作树
>
> 结论：实现边界符合首期约束；评审发现的阻塞性技术债已重构。2026-08-12 已补真实模型单作品
> 闭环证据，人工听感仍待用户确认。

## 1. 评审基准

评审以 `AGENTS.md`、`docs/requirements/product-requirements.md` 和当前可执行行为为准，检查：

- 当前用户闭环是否完整；
- 项目、版本和校验不变量是否只能通过明确边界改变；
- Provider、文件、子进程与取消错误是否被正确分类和传播；
- 是否存在由真实故障或重复开发成本证明的技术债；
- 是否提前引入第二 Provider、数据库、服务、后台 actor 或复杂崩溃协议。

## 2. 当前架构

```text
CLI / REPL
  ├── Project：项目文件、有效版本、恢复、导出路径
  ├── Agent：创作/修改/澄清/最多三轮修正
  │     ├── DeepSeekClient：一个 OpenAI-compatible 流式客户端
  │     └── AldaRunner：固定命令、校验、超时、取消、输出上限
  └── doctor / smoke：环境与真实能力证据
```

仍为单 crate、单进程、本地文件存储，没有新增通用 Provider/Store/Tool trait。

## 3. 发现与重构结果

| 级别 | 评审发现 | 需求依据 | 处理结果 |
|---|---|---|---|
| 阻塞 | Alda 同步校验会阻塞 async 任务，`Ctrl+C` 不能及时进入取消分支 | §13 用户可取消，子进程不得残留 | 校验移入可让出调度的阻塞边界；取消会终止整个进程组；黑盒集成测试证明及时退出且无残留 |
| 高 | 版本与项目约束字段公开可写，可绕过历史、时长和乐器不变量 | §7–§9 | 字段私有化；版本只允许领域方法改变，项目约束通过校验并持久化的 `configure` 修改 |
| 高 | 恢复旧版本后用 `current_version + 1` 会覆盖已有版本 | §8 既有版本不得覆盖 | 新版本固定取历史最大版本号加一；单元与重启集成测试覆盖 |
| 高 | 空 Alda 可解析成功并被误存为有效作品；截断标记跨轮残留 | §7 基础有效性与失败保护 | 增加声部/事件/非零时长检查；截断改为逐轮状态；修正成功测试覆盖 |
| 中 | 子进程读取错误被当作 EOF，输出错误可能静默丢失 | §13 可恢复错误不得伪装成功 | 读取线程传播 I/O 错误；stdout/stderr 均受上限约束 |
| 中 | HTTP mock 服务器在多个单元测试中复制 | 重复开发成本 | 合并到 `src/test_support.rs`；黑盒 E2E 仍保留独立实现以维持证据隔离 |
| 中 | 旧设计把 `/reload` 延后，与需求基线冲突 | §8.3 人工编辑 | 实现显式重新读取、校验、采用；失败时恢复当前有效版本 |
| 中 | 模型只提出澄清问题时被当作协议失败 | §8.1 范围不清先询问 | 增加 `needs_input` 状态并保留上下文，用户回答后继续生成 |
| 中 | 0/负数/非有限时长与互相冲突的乐器约束可进入网络和校验 | §7 可测量要求 | Agent 在网络前拒绝；Alda 与项目加载边界复核同一不变量 |
| 高 | 安装脚本会直接执行远程 `curl \| bash`，上游内容变化可在本机执行任意代码 | 明确供应链安全风险 | 删除远程脚本执行，改为指向官方人工安装说明；集成测试证明检查模式、已安装路径和拒绝提权路径都不会调用安装器或 `sudo` |
| 高 | REPL 没有入口设置项目模式、时长和乐器约束，真实版本化项目无法执行相应检查 | §6.2、§7、§9 | 为 `repl` 增加四组可选参数，仍通过 `Project::configure` 校验和持久化；未新增配置服务或第二套规则 |
| 高 | 当前真实模型在创作工具调用前返回数 MB 数据并超时，长时间占用请求且不能形成候选 | 真实完整曲目和短即兴均复现 | 错误链增加无凭证诊断与已接收字节数；工具参数增加 64 KiB 硬上限，提示和 schema 要求紧凑源码；模型仍未完成工具调用，保留为外部兼容性阻塞而不伪造成功 |
| 低 | 本地旧环境键名与规范示例并存，造成配置认知分叉 | 用户已完成迁移 | 删除旧别名，只接受三项 `ALDA_AGENT_*` 规范键名并增加拒绝旧键测试 |

## 4. 评审后保留的简单边界

以下没有当前问题证据，因此不作为技术债：

- 不提取 Provider、Store 或 Tool trait；
- 不引入数据库、事件溯源、WAL、分支版本或 CAS；
- 不实现多项目并发打开、多客户端或后台播放 actor；
- 不为对话提前实现 token 摘要；
- 不承诺复杂崩溃一致性，元数据只采用同目录临时文件替换。
