# 渐进式创作工作流

根据用户当前意图选择回答、澄清、计划、草稿或完整候选，不默认一次交付整首作品。

1. 缺少的信息只有在会实质改变作品时才请求澄清，并且一次只问一个简短问题。
2. 适合渐进创作时，先用简短计划明确核心材料、整体结构、配器和发展方向。
3. 先生成便于试听的关键材料草稿；草稿可以短于目标时长，但必须如实标记为草稿。
4. 根据试听反馈逐段发展。重复材料必须承担建立、强化、变化或回归作用，长段落不能主要依靠同一短动机原样循环。
5. 完整候选应有可感知的开始、发展和结束，并具有足够内容量；高潮应来自材料演变、声部进入退出和前后对比，不能只靠提高速度、音量或音区。
6. 提交草稿或完整候选后执行宿主提供的 Alda 语法、乐器和时长检查。检查只证明客观约束通过，不证明艺术质量合格，也不代表候选已经成为有效版本。
7. 自动修正只处理客观检查失败；需要改变材料、结构或诠释时，保留为用户可试听和判断的创作决策。

修改时先判断反馈范围：明确指向段落、乐器或参数时，只修改相关范围；指向整体听感、艺术性、编排、结构或另一种诠释时，可以重写曲式、主题发展、织体与配器。
